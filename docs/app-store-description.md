# LystBot App Store Description

## Deutsch (de-DE)

Deine KI plant dir das perfekte Abendessen für sechs Personen. Und dann? Tippst du die Zutaten von Hand in eine Einkaufsliste. Genau diese Lücke schließt LystBot.

LystBot ist eine Listen-App, in der dein KI-Agent nicht zuschaut, sondern mitarbeitet. Du gibst ihm einen API-Key, und ab da schreibt er direkt in deine Listen: Zutaten eintragen, Erledigtes abhaken, komplette Listen von Grund auf bauen. Kein Copy-Paste, kein "hier, füg das mal ein". Dein Agent erledigt es, dein Handy zeigt es. Sofort.

**So fühlt sich das an**

- "Plan mir drei Abendessen und setz alles auf die Einkaufsliste." Zwei Sekunden später steht sie da, sortiert und komplett.
- "Wir fliegen Freitag nach Lissabon, bau mir eine Packliste." Fertig, bevor du den Koffer aus dem Keller geholt hast.
- Du hakst im Supermarkt die Butter ab, und dein Agent weiß es. Deine Familie auch.

**Dein Agent wohnt schon da, wo LystBot andockt**

LystBot spricht die Sprachen, die Agenten verstehen: REST API, CLI und MCP. Damit funktioniert es mit ChatGPT, Claude Code, Codex, OpenClaw, Grok Bot, Cursor, Windsurf und allem anderen, das eine API aufrufen kann. Kein neues Ökosystem lernen. Dein Agent arbeitet dort weiter, wo er ohnehin lebt.

**Für Menschen genauso gut wie für Maschinen**

- Listen teilen per einfachem Code: Familie und Freunde sehen jede Änderung in Echtzeit.
- Push-Nachricht bei jeder Änderung, egal ob sie von einem Menschen kommt oder von einer KI.
- Amazon Alexa an Bord: Sachen einfach per Zuruf auf die Liste sprechen.
- Deutsch und Englisch.

**Loslegen in unter einer Minute**

Kein Konto, keine E-Mail, kein Passwort. App öffnen, erste Liste anlegen, fertig. Wenn du deinem Agenten Zugriff geben willst: API-Key erzeugen, übergeben, staunen.

Deine KI kann denken. Mit LystBot kann sie endlich auch erledigen.

## English (en-US)

Your AI can plan a week of dinners in ten seconds. But can it put milk on your shopping list?

Now it can.

LystBot is a list app where AI agents are first-class participants, not a chat window you copy things out of. Give your agent an API key and it manages your lists directly: adds items, checks them off, builds an entire packing list while you're still picking dates. You tell it what you need. It's on your phone before you've locked the screen.

Tell Claude Code to stock the grocery list for the week. Ask ChatGPT for a camping checklist and watch it appear, item by item. Let OpenClaw tidy your to-dos overnight. Your agent works where it already lives: OpenClaw, Claude Code, ChatGPT, Codex, Grok, Cursor, Windsurf, and anything else that speaks REST or MCP. The app simply shows what happened, live.

**How your agent connects**

- REST API for anything that can make an HTTP call
- CLI for terminal agents like Claude Code and Codex
- MCP server for quick setup in MCP-capable tools
- Push notification on every change, whether a human or an AI made it

**Built for real life**

- Grocery lists, to-dos, packing lists, custom lists
- Share any list with family and friends using a simple code
- Everyone sees changes in real time
- Add items by voice with Amazon Alexa

**No account, no friction**

- No email, no password, no signup. Open the app and go.
- Available in English and German

The gap between "my AI figured it out" and "it actually got done" has always been the annoying part of running agents. LystBot closes it for the most everyday things there are: what you need to buy, do, remember, and pack.
